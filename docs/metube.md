# MeTube native integration

- Primary regression reference: [cmbya/MeTube-fnOS](https://github.com/cmbya/MeTube-fnOS). Template icons, privilege/resource/UI, port 8081, package user, authorized-directory priority and logging are retained. The old network bootstrap is retained in the template as reference but excluded from the built FPK; callbacks use the embedded interpreter and offline deployment only.
- The existing central cron checks official MeTube releases, resolves tag to commit SHA, checks out that SHA and compares the version against FnDepot's published index. No independent per-app schedule.
- The fixed upstream Dockerfile defines the Node 22 builder digest, Python 3.14, frontend location, uv lock and FFmpeg 8.1 requirements. Frontend is actually compiled with pnpm 12.6.0 and its frozen lockfile. Backend source is copied unchanged. Neither the inspected shuangji66/FnDepot tree nor shuangji66/buildbot provided a MeTube recipe.
- Python standalone 3.14.8 is relocatable, not a copied venv. uv 0.13.1 exports frozen production requirements; installation verifies their hashes. Fixed Deno 2.9.7, bgutil 0.8.1 and its plugin are bundled. OpenSSL closure and CA roots are embedded. BUILD.json includes source SHA, lock digests, archive hashes and full payload file hashes.
- FFmpeg/ffprobe use fixed BtbN `autobuild-2026-10-16-13-04`, 8.1.3 release-branch build. This deliberately replaces old imageio 7.0.2 to match upstream HLS seeking/clip fix #1092; no silent latest assets. Licenses/notices ship in the bundle.
- Existing `${TRIM_PKGVAR}/native-runtime/home` (including cache), `state`, settings and download roots are preserved. Historical runtime components are backed up before replacing with package links. Download authorization falls back to the shared directory as before. Fake-IP compatibility remains enabled; use trusted LANs only. Provider binds loopback 4416, main UI remains 8081.
- CI checks ELF amd64/glibc <=2.36 and ldd closure. A separate clean Debian bookworm container, non-root and `--network none`, uses only the relocated embedded interpreter: imports, repeated actual install/upgrade callbacks, preservation sentinels, FFmpeg/ffprobe conversion, Deno, POT ping, lifecycle start/status/stop, homepage and version/history/subscriptions/cookie-status APIs. MeTube uses lazy atomic JSON state, not SQLite; actual AtomicJsonStore read/write is tested. Complete runtime inventory and lifecycle executable modes are checked inside the FPK.

## Limitations

No real NAS app services/data are touched; real fnOS installation/upgrade and live-site downloads are not validated. Native wrapper disables nightly pip self-updates to keep the offline locked environment coherent; updates come from new FPKs. Optional aria2 external downloader is not bundled. No claims of bypassing YouTube bot checks. Build containers require network, installed FPK does not require network for installation/startup. Platform glibc compatibility is bounded by CI ELF checks, not a claim about every NAS model.
