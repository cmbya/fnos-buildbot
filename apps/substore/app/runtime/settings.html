服务器持久配置

首次从飞牛 SSH 本机读取应用数据目录中的 fnos-settings.key，私下填入下框。管理密钥不显示在应用日志、网页或 URL 中，不要发送给他人。

以 / 开头，后接 4–128 个字母、数字、下划线或连字符（/ 不计入长度），例如 /aB12；系统和前端页面保留路径不可用。短路径更易猜到，推荐随机生成长路径。生成后直接在输入框明文显示；只有点击保存才会应用。修改成功后旧 API 前缀立即失效，其他设备及包含旧前缀的订阅/下载链接须更新。公开 /share 链接仍由原有分享令牌控制，不会因此自动撤销。一行一个或英文逗号分隔。必须包含协议，不带路径、末尾 / 或 *。自动生成的 NAS 内网来源始终保留。
